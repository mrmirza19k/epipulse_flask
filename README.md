# 🦠 EpiPulse AI — Intelligent Disease Outbreak Analyzer

EpiPulse AI is an AI-powered disease outbreak surveillance and analytics platform designed to monitor, analyze, forecast, and visualize disease spread across different districts.

The platform provides real-time outbreak insights using interactive dashboards, forecasting analytics, geo heatmaps, risk scoring, and AI-based disease prediction.

---

# 🚀 Features

## 📊 Interactive Dashboard

* Real-time disease monitoring
* Total case tracking
* Hospitalization analytics
* Active district monitoring
* Disease trend visualization

## 🔮 Forecasting System

* Predict future outbreak patterns
* Analyze historical disease trends
* AI-based forecasting charts

## ⚠️ Risk Analysis

## 🗺️ Geo Heatmap

* Location-based outbreak analysis

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/mrmirza19k/epipulse_flask.git
```

## 2️⃣ Move to Project Directory

```bash
cd epipulse_flask
```

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Flask Application

```bash
python app.py
```

---

## 6️⃣ Open in Browser

```bash
http://127.0.0.1:5000
```
